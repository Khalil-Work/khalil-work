# Profile artwork and layout

This profile uses four custom illustrated project identities. The covers are concept art, not solver output. Each cover carries its real project name, one short subject label, and KHALIL's signature. Each links to its project, with separate routes to methods and verification.

The portfolio retains the original supplied welcome banner, four featured studies, sixteen additional project links, the research toolkit and aviation/mountain interests. Project explanations remain selectable text; the supporting library uses ordinary links that wrap on narrow screens.

Images are stored in this repository. The main README does not depend on external badge, visitor-counter, trophy or statistics-image servers. Still-image links accompany the GIFs.

## Artwork production

The original artwork and typography were generated using the built-in image-generation tool, then encoded as restrained looping GIF covers. The wordmark region stays stationary. Motion is decorative lighting and gentle image motion; it is not a simulation of the represented physical phenomena.

Original source images and the numerical project result files remain separate. Editing the profile does not change any numerical solver or benchmark.

The original welcome image is stored without modification as `assets/welcome-matrix-e60fd09ecf46.png`.

See `assets/covers/animation-provenance.json` for image provenance and encoding checks.

## Compact gallery and personal accents

The four GIFs are arranged in two rows: Triangle Mesh Audit and Vortex Notebook, then Shockline and Droplet Journey. Each cover opens its repository. Short captions and visible project names accompany the artwork.

The moving introduction and thank-you line are self-hosted animated SVGs generated with [readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg). The original welcome banner remains unchanged. The smaller centered personal banner shows a hiker watching a fighter jet with the quote: “Aviation keeps me curious. Mountains help me reset.”
